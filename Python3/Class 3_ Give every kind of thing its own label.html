Why loose dictionaries are risky

A dictionary accepts anything and says nothing, so mistakes hide until much later.

Predict, then run each line

Guess first: does the line crash, or keep quiet? Then press it to see what Python really prints.

1case = {"case_id": "C-1002", "order_status": "SHIPPED", …}
press a line to run it

Run it

python scratch_dict.py
  • .get with a typo gives None. No error, so the mistake surfaces far from where it happened.
  • Any value fits. "Delivered" is not "DELIVERED", so the rule never sees the case as closed.
  • Only square brackets complained. The loud failure was the only useful one.
Think of it like thisA cloth bag of loose paper slips. You can push anything in, and nothing tells you a slip is misspelt until someone needs it.
Common slips
  • Expecting line 2 to crash. It prints None quietly.
  • Copying from the PDF splits line 1 in two. It still runs, but the traceback says line 6.
  • On Python 3.11+ the traceback shows a ~~~~^^^^ line pointing at the key. That is normal.

Classes and objects

A class is a blank form; each object is one filled-in copy holding one case’s values.

Fill in a form from cases.csv

Pick a row to build an object from it. Then add __repr__ and compare two copies.


  


  
Run it

  
python scratch_case.py


  

    
    
      
  • __init__ fills the form. Python calls it when you write Case(...).
    • 
      
  • self is the copy being filled right now. self.case_id = case_id writes on that copy.
    • 
      
  • Equal values are not equal objects. By default == asks “is it the very same copy?”
    • 
    

    
Think of it like thisThe form says there is a box called order_status. One copy says SHIPPED. Two copies with the same writing are still two pieces of paper.

  


  
Common slips
    
    
  • Forgetting self: Case.__init__() takes 4 positional arguments but 5 were given.
    • 
    
  • Writing case_id = case_id: the value vanishes, then 'Case' object has no attribute 'case_id'.
    • 
    
  • print inside __repr__ instead of return: __str__ returned non-string.
    • 
    
  • A missing comma joins two strings: missing 1 required positional argument.

  • The key lives in .env only. repr=False keeps it out of print(settings). Never log or save the settings object.
    • 
      
  • Bounded means three caps. Length (max_tokens), wait (timeout) and retries (max_retries=1), one call per flagged note.
    • 
      
  • Every answer is checked. An unknown family or a quote that isn’t in the note forces review. Text that isn’t JSON becomes an abstention.
    • 
    

    
Think of it like thisA shop counter with one hatch. Orders go out through it, and if the hatch is shut, you hand over yesterday’s labelled answer and say so.

  


  
Common slips

    • 
    
  • Leaving MERIDIAN_AI_MODE=live set in the terminal. A typo like recroded also goes live.
    • 
    
  • Removing the fallback “to see the real error”. Read meta.fallback_reason instead.
    • 
    
  • Committing .env. Read git status first.
